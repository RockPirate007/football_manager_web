# Football Manager Web

Браузерный футбольный менеджер в духе **FIFA Manager** — веб-порт терминальной
игры «Football manager.py» на **Next.js 16 + React 19 + TypeScript + Tailwind + Zustand**.

Реальный футбол вместо случайной генерации:

- **10 реальных лиг** в двух дивизионах: АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1
  плюс Чемпионшип, Сегунда, Серия Б, Вторая Бундеслига и Лига 2 — **192 клуба** с городами,
  реальными стадионами, вместимостью и цветами форм
- **780 реальных футболистов** с полной биографией: карьерный путь, достижения, стиль игры,
  номер, национальность, возраст, рейтинг и **точное амплуа** (FIFA-код).
  Вторые дивизионы собираются из правдоподобных генераций с национальными пулами имён (32 страны)
- **7 турниров**: 5 национальных кубков (объединяют оба дивизиона страны — как Кубок Англии
  в реальной жизни) + Лига чемпионов УЕФА + Лига Европы УЕФА
- **Повышения и понижения** между дивизионами по итогам сезона (3 вверх / 3 вниз в каждой стране)

## Позиции в стиле FIFA

15 детальных амплуа поверх четырёх групп:

| Линия | Коды |
|---|---|
| Вратарь | `GK` |
| Защита | `CB`, `LB`, `RB`, `LWB`, `RWB` |
| Полузащита | `DM`, `CM`, `LM`, `RM`, `AM` |
| Атака | `LW`, `RW`, `CF`, `ST` |

- каждая схема — это 11 конкретных слотов (например, 4-2-3-1: `GK LB CB CB RB DM DM LM AM RM ST`),
  всего 8 схем: 4-4-2, 4-3-3, 4-2-3-1, 5-3-2, 3-5-2, 4-1-4-1, 3-4-3, 4-3-1-2
- авто-состав подбирает игроков **под слоты** (амплуа + эффективность, приоритет реальным звёздам)
- матч учитывает соответствие: игрок не на своей позиции слабее (в экране состава — процент)

## Управление клубом (FIFA Manager-функционал)

- **Инфраструктура** — стройка клуба: стадион (расширение трибун, +6% мест за уровень),
  тренировочная база (восстановление и прогресс), академия (качество юниоров),
  медицинский центр (скорость лечения), фан-шоп (+15% мерча за уровень).
  Одна стройка одновременно, деньги списываются при старте
- **Молодёжная академия (U17/U19)** — возрастные группы, юниорские контракты (зарплата
  в 2–3 раза ниже взрослой), межсезонный набор с оценкой **класса поколения**
  («выдающийся … средний»), перевод в основу с автоподписанием **профконтракта**;
  отдельный тип командной тренировки «Академия»
- **Региональная скаутская сеть** — 8 регионов мира (топ-5 лиг, Южная Америка — алмазы
  с потолком-звездой, Африка — скорость, Восточная Европа — цена/характер):
  миссия стоит денег и идёт 2–3 тура, отчёт приходит письмом; точность оценки (±1…±8)
  и число параллельных миссий (1–2) зависят от скаута и аналитика в штате;
  кандидаты открываются на рынке свободных агентов
- **Тактика глубже** — **индивидуальные установки** игрокам (придерживаться позиции /
  подключения к атаке / жёсткий прессинг / беречь силы — влияют на линии, прессинг
  и усталость в матче) и **стандарты**: назначьте исполнителей штрафных и угловых —
  их навес повышает xG моментов, голы со стандартов получают отметку в трансляции
- **Индивидуальные планы тренировок** — до 3 игроков с фокусом атрибута
  (скорость / удар / пас / оборона): атрибут растёт еженедельно автоматически,
  тренер и база усиливают эффект
- **Совет директоров (жёсткий)** — сезонные цели по силе клуба, обзоры на 25/50/75%
  сезона, **ультиматумы с дедлайном** (не исправите положение — контракт расторгнут),
  реакция на **кубковые сенсации** (вылет от слабого соперника бьёт по доверию)
- **Финансовый fair play** — три зоны: норма (≤115% ведомости к доходам) →
  предупреждение (>125% при пустом бюджете) → **санкции**: штраф 1,5 млн € и
  **запрет покупок/аренд на 6 туров** при ведомости >145% при минусе на счету
- **Спонсоры и мерч** — титульный контракт с платежом за тур, сроком и бонусом
  за место; рынок предложений (подъёмные, требования к репутации, предложения
  «стареют» и уходят); перезаключение в межсезонье; мерч растёт от фан-шопа,
  репутации и престижа лиги; **билетная политика** — назначайте цену (эластичность:
  +20% к цене ≈ −27% зрителей) или оставьте авто
- **Лента новостей** — живой медиапоток: результаты, лидеры лиги, бомбардирская гонка,
  стройки, решения совета, топ-матчи Европы (фильтры: Клуб / Лига / Европа / Мир)
- **Календарь сезона** — все турниры по месяцам: матчи чемпионата, раунды кубка,
  жеребьёвки и стадии ЛЧ/ЛЕ, окна сборных, трансферные окна
- **Сборные** — вызовы игроков на товарищеские матчи, Евро и ЧМ: письмо-предупреждение
  за тур до окна, письмо с вызовами и результатами, усталость от перелётов
- **Персонал** — 6 специалистов (ассистент, тренер, скаут, физиотерапевт, физио-подготовка,
  аналитик) с наймом/увольнением и еженедельными эффектами
- **Пресс-конференции** — после побед, поражений, в кризисы и в трансферные окна:
  ответы журналистам влияют на мораль, доверие и репутацию
- **Живой матч** — трансляция 2D-поле с фишками в цветах форм, замены и установки
  по ходу, командные установки в перерыве; или быстрый результат
- **Экономика** — билеты (посещаемость от места/формы/репутации и назначенной цены),
  мерч, спонсорский контракт, выравнивающие выплаты лиги, призовые, содержание
- **Динамика лиг** — у каждой из 10 лиг **престиж 0–100**, который живёт:
  победы клубов в еврокубках (+4 за ЛЧ), чемпионство, сила повышающихся;
  **ТВ-деньги = база дивизиона × престиж лиги × доля по месту** — лидер АПЛ
  получает ~483 тыс € за тур, аутсайдер ~357 тыс; изменения — в ленте новостей
- **Сложность** — Легко / Нормально / Сложно / Легенда + режим песочницы (бесконечные деньги)
- **Многосезонье** — старение легенд, вундеркинды, живой трансферный рынок ИИ, приглашения
  в другие клубы, архив сезонов

Меню в стиле FIFA Manager: горизонтальное меню с выпадающими разделами
(Клуб / Команда / Менеджмент / Ещё), читаемый статус-бар чипами, на мобильных —
нижняя панель и выдвижное меню «Ещё».

## Быстрый старт

Требуется Node.js 18+ (или Bun 1.1+).

```bash
npm install          # или: bun install
npm run dev          # или: bun run dev
```

Откройте в браузере: http://localhost:3000

> Игра работает полностью на клиенте и хранит сохранения в localStorage —
> база данных (Prisma) для самой игры не нужна.

## Продакшен-сборка

```bash
npm run build
npm start            # NODE_ENV=production, standalone-сервер Next.js
```

## Архитектура (clean architecture, слои без циклических зависимостей)

```
src/
├── game/
│   ├── data/            # ДАННЫЕ: 10 лиг и 192 клуба, 780 реальных игроков,
│   │                    #   схемы-слоты, тактики, роли, пулы имён, пресса
│   ├── core/            # ДОМЕН: типы, Player/Team, позиции (pos.ts),
│   │                    #   RNG (gauss/weighted), деньги, биографии
│   ├── engine/          # МАТЧЕВЫЙ ДВИЖОК: xG-профили, шансы, события,
│   │                    #   оценки, живая сессия матча
│   ├── systems/         # 20 СИСТЕМ: расписание, финансы, тренировки (вкл. индивидуальные
│   │                    #   планы и «Академию»), контракты, трансферы, переговоры,
│   │                    #   карьера, молодёжная академия U17/U19, скаутинг (экспресс +
│   │                    #   региональная сеть с миссиями), кубки, почта, рынок, тур/сезон,
│   │                    #   персонал, пресса, инфраструктура, совет директоров (ультиматумы,
│   │                    #   FFP-санкции), лента новостей, раздевалка, сборные, живой матч,
│   │                    #   динамика лиг (престиж/ТВ), коммерция (спонсоры/билеты)
│   ├── persistence/     # Сериализация v13 с миграциями (ключ fm_web_save_v10,
│   │                    #   сейвы v7+ мигрируются: 2-е дивизионы, инфраструктура,
│   │                    #   юниорские контракты, стандарты/установки, престиж,
│   │                    #   спонсоры и FFP дефолтами)
│   └── store/           # Zustand-стор: ~40 игровых действий
├── components/game/     # UI: GameShell (dropdown-меню FIFA-стиля), 17 экранов,
│                        #   4 диалога, логотипы клубов и турниров
└── lib/                 # Утилиты, Prisma-клиент (каркас)
```
